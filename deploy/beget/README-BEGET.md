# Запуск CarpetLAB на VPS Beget — пошагово

Подходит **VPS (Beget Cloud)** с Ubuntu 22.04 или 24.04. На обычном виртуальном хостинге Beget система работать не будет: ей нужны PostgreSQL с собственными ролями, Node.js 22 и постоянно работающая служба.

## Что заказать и подготовить (в личном кабинете Beget)
1. **Облачный VPS**: Ubuntu 22.04/24.04, не меньше **2 ГБ памяти**, 1–2 ядра, диск от 20 ГБ. Регион в РФ (152-ФЗ). Запишите **IP-адрес** и пароль `root` (его покажет Beget).
2. **Домен** (например `carpet.ваш-домен.ru`). В DNS-настройках домена создайте **A-запись**, указывающую на IP вашего VPS. Подождите 5–30 минут, пока она заработает. Домен нужен для HTTPS: без него вход в кабинет работать не будет.
3. Для писем (приглашения сотрудников, подтверждение e-mail) нужен **SMTP-сервер** (почта вашего домена на Beget подойдет). Для оплаты картой нужны **ShopID и секретный ключ ЮKassa**. Без них сайт запустится, но письма не отправляются, а оплата картой недоступна.

## Установка (один раз, ~10 минут)
Все команды выполняются на сервере. Чтобы подключиться, откройте на своем компьютере программу «Терминал» (Windows 10/11: «PowerShell») и введите:
```
ssh root@IP_ВАШЕГО_СЕРВЕРА
```
(согласитесь с вопросом `yes` и введите пароль root).

**1. Загрузите архив на сервер.** На своем компьютере (не на сервере) в новом окне терминала, из папки со скачанным архивом:
```
scp carpetlab-beget-*.zip root@IP_ВАШЕГО_СЕРВЕРА:/root/
```
(либо загрузите файл программой FileZilla или WinSCP в каталог `/root`).

**2. Распакуйте** (в окне, подключенном к серверу):
```
apt-get update && apt-get install -y unzip
unzip -q /root/carpetlab-beget-*.zip -d /opt
cd /opt/carpetlab
```

**3. Запустите установку** (подставьте ваш домен и e-mail для сертификата):
```
DOMAIN=carpet.ваш-домен.ru EMAIL=вы@ваш-домен.ru bash deploy/beget/install.sh
```
Скрипт сам поставит PostgreSQL, Node.js и nginx, создаст базу и пароли, соберет и запустит сайт, выпустит бесплатный сертификат HTTPS и включит ежедневную резервную копию. В конце напишет `ГОТОВО. Откройте: https://…`.

**4. Закройте лишние порты** (безопасность):
```
ufw allow OpenSSH && ufw allow 'Nginx Full' && ufw --force enable
```

## После установки
- Откройте сайт, зарегистрируйтесь, пройдите сценарий.
- **Стать администратором сервиса** (цены тарифов, подтверждение счетов): 
  `PGPASSWORD=$(grep DB_ADMIN_PASSWORD /etc/carpetlab.env | cut -d= -f2) psql postgresql://carpet_admin@localhost:5432/carpetlab -c "UPDATE \"User\" SET \"isServiceAdmin\"=true WHERE email='вы@ваш-домен.ru'"`, затем выйдите и войдите снова. В разделе «Админ» задайте цены.
- **Почта и оплата:** откройте `nano /etc/carpetlab.env`, заполните `SMTP_URL` (например `smtps://логин:пароль@smtp.beget.com:465`), `MAIL_FROM`, `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`. Сохраните (Ctrl+O, Enter, Ctrl+X) и выполните `systemctl restart carpetlab-backend`. В кабинете ЮKassa укажите адрес уведомлений: `https://ваш-домен/api/billing/yookassa/webhook`.

## Обслуживание
- Журнал: `journalctl -u carpetlab-backend -f`. Перезапуск: `systemctl restart carpetlab-backend`.
- **Резервные копии** лежат в `/var/backups/carpetlab` (ежедневно в 03:15, хранятся 14 дней). **Обязательно копируйте их на другой сервер**: копия на том же диске не спасет при потере VPS. Проверка восстановления: `deploy/verify-restore.sh`, инструкция в `deploy/restore.md`.
- **Обновление** на новую версию: загрузите новый архив, распакуйте поверх (`unzip -qo … -d /opt`) и снова запустите команду из шага 3. Данные и пароли сохраняются.
