# CarpetLAB
Сервис учета и раскроя ковров. Документы: `docs/superpowers/specs`, `docs/superpowers/plans`.
Запуск dev: PostgreSQL 16 (см. `docker-compose.yml` или локальный), `cd backend && npm test`.

## Администратор сервиса
Администратор CarpetLAB (цены тарифов, подтверждение счетов) назначается в БД:
`UPDATE "User" SET "isServiceAdmin" = true WHERE email = 'you@example.com';`

## Как проверить систему целиком (без установки чего-либо у себя)
Нужен только аккаунт GitHub. Репозиторий → зеленая кнопка **Code** → вкладка **Codespaces** → **Create codespace on build/carpetlab-v1**.
1. Подождите 3–5 минут: среда сама поставит PostgreSQL, зависимости и применит миграции (`scripts/dev-setup.sh`).
2. В терминале внизу выполните: `bash scripts/dev-start.sh`
3. Во вкладке **Ports** откройте адрес порта **5173** (значок глобуса). Это настоящий сайт: данные хранятся в базе, PDF и этикетки формируются.
4. Зарегистрируйтесь (письма в разработке пишутся только в консоль, регистрация работает без них).
5. Чтобы открыть раздел «Админ» (цены тарифов, подтверждение счетов): `bash scripts/make-admin.sh ваш@email`, затем выйдите и войдите снова.

Остановка: `Ctrl+C` в терминале. Запуск снова: `bash scripts/dev-start.sh` (повторная настройка не нужна). Проверка автотестами: `cd backend && npm test`, `cd frontend && npm test`; сквозной сценарий в браузере: `e2e/run.sh`.
